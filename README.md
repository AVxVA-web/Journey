# Journey OS

واجهة عربية داكنة ومقسمة إلى أقسام مستقلة لطلاب ثالثة ثانوي. الفكرة هي تحويل رحلة الثانوية العامة خلال 52 أسبوعًا إلى نظام قيادة gamified يضم التقدم، التخطيط، المهام، التركيز، التحليل، والطاقة.

## الأقسام

- **القيادة:** مؤشرات XP، المستوى، الالتزام، جودة التركيز، وأفضل خطوة تالية.
- **رحلة 52 أسبوع:** خريطة تفاعلية للأسابيع مقسمة إلى عوالم دراسية.
- **التخطيط:** خطة أسبوعية واضحة مع قواعد مذاكرة قابلة للتنفيذ.
- **المهام:** تحديات يومية بنقاط XP.
- **التركيز:** غرفة Pomodoro لجلسات Deep Work.
- **التحليل:** رؤى عن نقاط الضعف وأفضل أوقات المذاكرة.
- **الطاقة:** تتبع العادات الأساسية والرفاهية.

## التشغيل

افتح `index.html` مباشرة في المتصفح، أو شغّل خادمًا محليًا:

```bash
python3 -m http.server 4173
```

## الفحص

```bash
npm test
```
